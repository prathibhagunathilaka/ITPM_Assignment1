\# Test Automation Project (Playwright + Excel)



\## Project Overview

This project automates translation test cases using Python Playwright.

It reads input data from an Excel file and sends it to a web-based chat translator, then compares actual output with expected output and marks PASS/FAIL.



\---



\## ⚙️ Technologies Used

\- Python 3.14.4

\- Playwright

\- openpyxl



\---



\## Project Files

\- test\_automation.py → Main automation script

\- Assignment 1 - Test cases.xlsx → Test data file

\- requirements.txt → Required Python libraries

\- README.md → Project documentation
